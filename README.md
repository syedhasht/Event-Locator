# Event-Locator
This is a basic app that lets users find local events. The front end is built using XML (for Android layouts), and the back end uses Firebase to store and retrieve event data.

Features:

Users can view a list of events

Event details like name, date, time, and location

Data is stored and synced using Firebase Realtime Database

Tech Stack:

Front End: Android XML (Java or Kotlin for logic)

Back End: Firebase Realtime Database / Firestore

Usage:

Add events in Firebase

App fetches and displays them on the screen

Can be expanded to include event filtering, maps, or user submissions

Just a simple event-finding app using basic tools. Great for learning how to connect Android with Firebase!
